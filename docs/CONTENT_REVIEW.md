# مراجعة محتوى الألعاب

`src/content/packs/seed.json` بدأ بمحتوى الديمو ثم أضيفت إليه مسودات حتى العدد المستهدف؛ كل الحزم ما زالت **غير معتمدة للمتجر**. أمر `npm run content:lint` يفحص الشكل والمعرّفات والكلمات المحظورة ويطبع العدد والبصمة لكل مجموعة. أمر `npm run content:lint -- --release` يرفض الإطلاق إذا نقص العدد أو لم تُعتمد كل مجموعة من شخصين مختلفين.

لإعداد نسختين مستقلتين للمراجعة شغّل `npm run content:review-export`. سينشئ `review-packets/reviewer-1.csv` و`review-packets/reviewer-2.csv` بكل العناصر، بما فيها العقوبات الخفيفة، مع معرّف الحزمة وبصمتها وعمودي القرار والملاحظة. مجلد التصدير محلي وغير مرفوع إلى GitHub. شارك كل نسخة مع مراجع مختلف؛ الملفات المعبأة تساعد التحرير لكنها **لا تتحول تلقائيًا إلى اعتماد**.

للمراجعة التحريرية:

1. يقرأ المراجع الأول **كل** عناصر المجموعة في سياق اللعبة، ويعدل أو يستبعد ما يحتاج. راجعوا طبيعية المصري، طول العبارة، وضوح اللعب، وملاءمة العائلة. في التحديات ارفضوا الخطر، إيذاء النفس، إتلاف الممتلكات، الإنفاق، التواصل مع غرباء، أو النشر دون موافقة اللاعب.
   في حزمة الأمثال راجعوا نص المثل الشائع وتكملته بدقة، واحذفوا أي عبارة مؤلفة تبدو مثلًا وليست كذلك. يمكن مقارنة الصيغ بمراجع تراثية مثل [بوابة محافظة القاهرة](https://cairo.gov.eg/ar/culture/cultural-variety/egyptian-proverbs/) و[نسخة الأمثال العامية القديمة](https://commons.wikimedia.org/wiki/File:%D8%A7%D9%84%D8%A3%D9%85%D8%AB%D8%A7%D9%84_%D8%A7%D9%84%D8%B9%D8%A7%D9%85%D9%8A%D8%A9-_%D9%85%D8%B4%D8%B1%D9%88%D8%AD%D8%A9_%D9%88%D9%85%D8%B1%D8%AA%D8%A8%D8%A9_%D8%B9%D9%84%D9%89_%D8%A7%D9%84%D8%AD%D8%B1%D9%81_%D8%A7%D9%84%D8%A3%D9%88%D9%84_%D9%85%D9%86_%D8%A7%D9%84%D9%85%D8%AB%D9%84_%28%D8%A7%D9%84%D8%B7%D8%A8%D8%B9%D8%A9_%D8%A7%D9%84%D8%AB%D8%A7%D9%86%D9%8A%D8%A9%29.pdf) مع الاستخدام الحالي، دون نقل مجموعات نصوص من مصدر واحد.
2. يراجع شخص ثان مستقل المجموعة بعد التعديلات. لا تعتمدوا مجموعة بمراجعة أسماء شكلية.
3. شغّلوا `npm run content:lint`، ثم ضعوا بصمة SHA-256 الكاملة للمجموعة في `docs/content-reviews.json` مع اسمي المراجعين المختلفين وتاريخ `YYYY-MM-DD`:

```json
{
  "schemaVersion": 1,
  "packs": {
    "base-likely": {
      "hash": "...64 hex characters from packHash...",
      "reviewers": ["الاسم الأول", "الاسم الثاني"],
      "reviewedAt": "2026-09-30"
    }
  }
}
```

استخدم معرّف `punishments` لاعتماد بطاقات العقوبات بالطريقة نفسها. أي تعديل لاحق على عناصر المجموعة أو العقوبات يغيّر بصمتها ويلغي الاعتماد آليًا حتى يعيد الشخصان مراجعتها. الكاشف الآلي لا يقدر يحكم على النكتة أو السياق، لذلك الاعتماد البشري شرط مستقل عن نجاح الأمر.
