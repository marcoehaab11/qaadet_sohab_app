## قبل الإطلاق العام

1. مراجعة كل حزمة تحريرياً من شخصين مستقلين، مع تدقيق خاص للأمثال والتحديات، ثم تشغيل `npm run content:lint -- --release` حتى ينجح. يمكن بناء نسخة اختبار داخلي وتجربتها أثناء سير هذه المراجعة، مع عدم تقديمها كنسخة إطلاق عام.
2. اعتماد الأيقونة وصور المتجر بعد تجربة الهاتف ومراجعة نصوص الصفحة.
3. تأكيد معرّف الحزمة واسم المطور، ثم إنشاء APK اختبار بـ `npx eas-cli@latest build --platform android --profile preview` عند الحاجة. لا تحفظ بيانات الدخول أو مفاتيح التوقيع في Git.
4. جرّب APK على هاتف Android حقيقي: RTL، الخط الكبير، TalkBack، الوضع العائلي، المؤقت مع قفل الشاشة والعودة، الصوت/الاهتزاز، حفظ البيانات دون إنترنت، الألعاب الإحدى عشرة، وضع الفرق، الرسم باللمس، المواسم، نتيجة المباراة ومشاركة صورتها ونصها، وطلب التقييم بعد القعدة الثالثة. سجّل الأجهزة وإصدارات النظام ونتائج الاختبار. اختبر نسخة iOS على جهاز حقيقي قبل الادعاء بدعمها الكامل.
5. راجع أذونات وSDKs حزمة Android النهائية واملأ نموذج Data safety بما يحدث فعلًا. بريد التواصل الرسمي مضاف إلى سياسة الخصوصية، وتأكد من أن رابطها متاح علنًا داخل Play Console.

## الرفع التجريبي وبعده

1. أكمل بيانات Play Console: تصنيف المحتوى، الفئة العمرية، بريد الدعم، سياسة الخصوصية، ونموذج Data safety، ثم أرسل صفحة المتجر للمراجعة. تحقّق من متطلبات الاختبار والحساب السارية وقت الإطلاق.
2. اختبر الإصدار الحالي عبر المسار الداخلي في Play Console. أعد البناء بعد أي تعديلات نتجت عن المراجعات وقبل طلب الإطلاق العام. الملف المصدر وحده و`expo export` لا ينتجان AAB.
3. الانتقال من الاختبار إلى الإنتاج قرار منفصل بعد نتائج الأجهزة ومراجعة المتجر. لا تشغّل `eas submit` تلقائيًا عند كل push.

إذا كان حساب المطوّر شخصيًا وأُنشئ بعد 13 نوفمبر 2023، فالوصول للإنتاج يتطلب اختبارًا مغلقًا فيه 12 مختبرًا منضمين باستمرار لمدة 14 يومًا، ثم طلب الوصول للإنتاج؛ [المصدر الرسمي](https://support.google.com/googleplay/android-developer/answer/14151465). الاختبار الداخلي ممكن قبل اكتمال إعداد صفحة التطبيق، لكنه لا يحل محل هذا الشرط.

اعتبارًا من 31 أغسطس 2026، تتطلب تطبيقات Android الجديدة والمحدثة على Play استهداف API 36. Expo SDK 57 يستهدف API 36 افتراضيًا؛ راجع قيمة الهدف في AAB النهائية قبل الرفع.
