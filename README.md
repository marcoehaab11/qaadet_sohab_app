# قعدة صحاب

تطبيق ألعاب بالمصري، على موبايل واحد، من غير حسابات أو إنترنت.

## الحالة الحالية

الأساس وواجهة التطبيق موجودين، مع مقدمة من ٣ خطوات، إدارة القعدة واللاعبين، ترتيب الألعاب، وصفحة النتائج. الألعاب الثمانية الأساسية قابلة للتجربة من الترابيزة أو أثناء القعدة: **Imposter**، **كوتشينة بس مختلفة**، **مين غالبًا؟**، **ممنوع تقول**، **Truth or Dare**، **تمثيل**، **أسرع واحد**، و**مين يعرفني أكتر؟**. **دي نسخة تطوير، مش جاهزة للنشر على Google Play**؛ المحتوى قليل والاختبار على أجهزة حقيقية ومتطلبات المتجر لسه مفتوحة.

الموجود: Expo SDK 57، TypeScript strict، Expo Router، خطوط محلية، RTL، حفظ اللاعبين والإعدادات وأسئلة الشلة المخصصة، وضع العيلة، محرك نقاط وتراجع، اختيار محتوى بدون تكرار، ترتيب أدوار، منطق تايمر، ومكونات تمرير الموبايل وإخفاء السر. أثناء القعدة يمكن تغيير حضور اللاعب وإضافة لاعب جديد. النقاط وحالة القعدة مؤقتة وتختفي عند إغلاق التطبيق. يوجد 236 عنصر محتوى أولي من الديمو. طلب التقييم الأصلي مجهّز بعد القعدة الثالثة في نسخة الإنتاج، لكنه لم يُختبر بعد على جهاز مثبت من المتجر.

## التشغيل

استخدم Node.js 22.13 أو أحدث؛ إصدار LTS مناسب للتطوير.

```sh
npm ci
npm run web
```

للتجربة على Android:

```sh
npm start
```

افتح المشروع من Expo Go المتوافق مع SDK 57 أو من development build. إعدادات RTL الأصلية تتأكد على development build، لأن Expo Go لا يطبق كل إعدادات المشروع الأصلية.

```sh
npm run check
npx expo export --platform android
```

أمر export بيتحقق من تجميع JavaScript وملفات التطبيق؛ مش بيطلع APK أو AAB.

## المراحل الجاية

1. استكمال M2: تحسين اختبار الهاتف الحقيقي وتدفق القعدة مع ألعاب إضافية.
2. M3: الأربع ألعاب الأولى قابلة للتجربة؛ يلزم استكمال المحتوى واختبارها على الأجهزة.
3. M4: الألعاب الثمانية الأساسية قابلة للتجربة؛ يلزم تقوية الاختبارات والتجربة على الأجهزة.
4. M5: أسئلة الشلة، وضع العيلة، وطلب التقييم منفّذين؛ يلزم اختبار جهاز حقيقي واستكمال تجهيز صفحة المتجر.
5. M6: استكمال المحتوى ومراجعته من شخصين، رمضان، واختبار Android وiOS على الأجهزة.

التفاصيل في [المواصفات](docs/SPEC.md)، والقرارات والفروق في [DECISIONS.md](DECISIONS.md).

## المحتوى

```sh
node scripts/import-prototype.mjs
npm run content:lint
npm run content:lint -- --release
```

الفحص الأخير مطلوب للإطلاق وهيفشل حاليًا لأن محتوى النسخة الأولية أقل من المطلوب. فحص الكلمات الآلي لا يغني عن المراجعة البشرية.

## النشر لاحقًا

قبل Google Play: اسم حزمة نهائي، حساب Play Console وExpo، توقيع ونسخة AAB، أيقونة وصور متجر نهائية، وصف وسياسة خصوصية دقيقة، ومراجعة متطلبات Google Play وقت النشر. أيقونات Expo الموجودة مؤقتة. لم يتم إنشاء إصدار متجر أو رفع أي بيانات.
