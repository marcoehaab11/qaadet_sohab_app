# قعدة صحاب

تطبيق ألعاب بالمصري، على موبايل واحد، من غير حسابات أو إنترنت.

## الحالة الحالية

الأساس وواجهة التطبيق موجودين، مع مقدمة من ٣ خطوات، إدارة القعدة واللاعبين، ترتيب الألعاب، وصفحة النتائج. الألعاب الثمانية الأساسية وألعاب **كمّل المثل** و**Memory Battle** و**ارسم وخمّن** من v1.1 قابلة للتجربة من الترابيزة أو أثناء القعدة. **دي نسخة تطوير، مش جاهزة للنشر على Google Play**؛ المحتوى قليل والاختبار على أجهزة حقيقية ومتطلبات المتجر لسه مفتوحة.

الموجود: Expo SDK 57، TypeScript strict، Expo Router، خطوط محلية، RTL، حفظ اللاعبين والإعدادات وأسئلة الشلة المخصصة، وضع العيلة، محرك نقاط وتراجع، اختيار محتوى بدون تكرار، ترتيب أدوار، منطق تايمر، ومكونات تمرير الموبايل وإخفاء السر. أثناء القعدة يمكن تغيير حضور اللاعب وإضافة لاعب جديد. النقاط وحالة القعدة مؤقتة وتختفي عند إغلاق التطبيق، لكن سجل القعدات المكتملة والإحصاءات محفوظان محليًا. يوجد 1400/1400 عنصرًا من المحتوى الأساسي، و65 عنصرًا لكل موسم من رمضان والعيد والساحل والامتحانات، و120/120 مثلًا، و200/200 كلمة رسم. المحتوى مسودة تحتاج مراجعة تحريرية من شخصين؛ اكتمال العدد لا يعني جاهزية النشر. طلب التقييم الأصلي مجهّز بعد القعدة الثالثة في نسخة الإنتاج، لكنه لم يُختبر بعد على جهاز مثبت من المتجر.

## التشغيل

استخدم Node.js 22.13 أو أحدث؛ إصدار LTS مناسب للتطوير.

```sh
npm ci
npm run web
```

للتجربة على Android:

```sh
npm start
```

افتح المشروع من Expo Go المتوافق مع SDK 57 أو من development build. إعدادات RTL الأصلية تتأكد على development build، لأن Expo Go لا يطبق كل إعدادات المشروع الأصلية.

```sh
npm run check
npx expo export --platform android
```

أمر export بيتحقق من تجميع JavaScript وملفات التطبيق؛ مش بيطلع APK أو AAB.

## المراحل الجاية

1. استكمال M2: تحسين اختبار الهاتف الحقيقي وتدفق القعدة مع ألعاب إضافية.
2. M3: الأربع ألعاب الأولى قابلة للتجربة؛ يلزم استكمال المحتوى واختبارها على الأجهزة.
3. M4: الألعاب الثمانية الأساسية قابلة للتجربة؛ يلزم تقوية الاختبارات والتجربة على الأجهزة.
4. M5: أسئلة الشلة، وضع العيلة، طلب التقييم، مسودة الخصوصية، وإعداد EAS منفّذين؛ يلزم اختبار جهاز حقيقي وتجهيز صفحة المتجر النهائية.
5. M6: حزمة رمضان والكشف التلقائي منفّذان؛ باقي المحتوى الأساسي ومراجعته من شخصين واختبار Android وiOS على الأجهزة.
6. M7: كمّل المثل، Memory Battle، ارسم وخمّن، وضع الفرق، وصعوبة ممنوع تقول قابلة للتجربة؛ مراجعة المحتوى وتجربة الأجهزة باقيان.
7. M8: ألقاب القعدة والعقاب الخفيف ومفاجآت القعدة وجولة الحسم والسجل والإحصاءات وبطاقة النتيجة ومشاركتها منفّذة؛ اختبار مشاركة الصورة على Android وiOS باقي.
8. M9: حزم المواسم والتبديل اليدوي منفّذة، وكل مجموعات المحتوى وصلت لأعدادها المستهدفة. باقي مراجعة المحتوى من شخصين لكل مجموعة، وتصحيح ما يلزم، وتجربة الإصدار على الأجهزة.

التفاصيل في [المواصفات](docs/SPEC.md)، والقرارات والفروق في [DECISIONS.md](DECISIONS.md).

## المحتوى

```sh
node scripts/import-prototype.mjs
npm run content:lint
npm run content:lint -- --release
```

الفحص الأخير مطلوب للإطلاق وهيفشل حاليًا لأن محتوى النسخة الأولية أقل من المطلوب ولم يراجعه شخصان. خطوات الاعتماد في [مراجعة المحتوى](docs/CONTENT_REVIEW.md). فحص الكلمات الآلي لا يغني عن المراجعة البشرية.

## النشر لاحقًا

قبل Google Play: تأكيد اسم الحزمة المقترح، حساب Play Console وExpo، توقيع ونسخة AAB، اعتماد الأيقونة الحالية وصور متجر نهائية، وصف وسياسة خصوصية دقيقة، ومراجعة متطلبات Google Play وقت النشر. لم يتم إنشاء إصدار متجر أو رفع أي بيانات. التفاصيل في [قائمة تجهيز المتجر](docs/PLAY_RELEASE.md).
